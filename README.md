# StrideShop Starter Project

This workspace contains a simple online shoe shop starter site using:
- HTML for the landing page
- CSS for styling
- JavaScript for product cards
- Python (Flask) for a simple API
- PHP for a simple API

## Files
- index.html
- assets/css/style.css
- assets/js/app.js
- backend/python/app.py
- backend/python/requirements.txt
- backend/php/api.php

## Run
1. Start the Flask shop server:
   - cd backend/python
   - pip install -r requirements.txt
   - python app.py
2. Open http://127.0.0.1:5000/ in your browser.
3. The site now uses SQLite-backed product and order storage.
4. Seller key for the add-product form: seller2026
